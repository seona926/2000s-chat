# 접속중

2000년대 포털 채팅의 로비와 메신저 화면을 재현한 실시간 채팅 웹앱입니다.
자동 닉네임으로 들어와 방 목록에서 인원을 보고 입장하거나 랜덤 1:1을 시작할 수 있습니다.

## 로컬 실행

Node.js 22 이상을 사용합니다.

```bash
npm ci
npm run dev
```

터미널에 출력된 로컬 주소를 엽니다. 일반 창과 시크릿 창을 각각 열면 게스트 두 명으로 확인할 수 있습니다.
공개방에서 한 줄씩 메시지를 보내고, 로비에 돌아와 두 창 모두 랜덤 1:1을 시작합니다. 채팅 하단에서 이모지, 사진, 글꼴, 크기, 색상, 굵게, 기울임, 밑줄을 선택할 수 있습니다. 사진은 브라우저에서 640px 이하 JPEG로 줄여 전송하고 기록은 접속 중인 사용자에게만 전달합니다.
화면이 700px 이하이면 로비는 1열이며 채팅방의 접속자 목록은 상단 버튼에서 열립니다.
프런트엔드 수정 내용을 반영하려면 개발 서버를 다시 시작합니다.

## 구성

- React, TypeScript, Vite로 화면을 구성합니다.
- Cloudflare Workers가 정적 파일과 WebSocket 진입점을 제공합니다.
- SQLite 기반 Durable Object 하나가 공개방과 매칭을 관리합니다. WebSocket 연결에 게스트 상태를 저장하므로 유휴 상태에서도 복구할 수 있습니다.
- 이미 접수된 신고는 SQLite의 reports 테이블에 저장합니다. 신고 접수는 현재 방의 최근 메시지에 한해 가능하며, 그 임시 메시지 목록은 런타임 메모리에 보관합니다.

운영자용 신고 목록 화면은 이 버전에 포함되어 있지 않습니다. 로컬에서는 Wrangler Local Explorer에서 SQLite 저장 상태를 확인할 수 있습니다.

## 배포 시 실행

Cloudflare Workers Free 계정에서 Wrangler에 로그인한 뒤 실행합니다. 계정의 기본 workers.dev 주소를 사용합니다.

```bash
npx wrangler login
npm run deploy
```

배포 이후에는 PC와 실제 휴대폰에서 공개방 메시지 교환과 랜덤 1:1 연결을 확인합니다.
